# Jagannath Temple – 8 Mysteries

A Remotion video project exploring eight popular mysteries and traditions associated with the Jagannath Temple in Puri, Odisha.

## Project Overview

This project uses [Remotion](https://www.remotion.dev/) to create an animated video about the eight mysteries of the Jagannath Temple. The narration is in Hindi and includes voice-direction cues, pauses, and sound-effect cues for editing.

## Requirements

- Node.js
- npm
- Remotion dependencies installed in the project

## Commands

### Install dependencies

```bash
npm install --loglevel=error
```

### Start the preview

```bash
npm run dev
```

### Render the video

```bash
npx remotion render
```

If your project has a named composition, specify its composition ID:

```bash
npx remotion render src/index.ts <composition-id> out/jagannath-mystery.mp4
```

Replace `<composition-id>` with the actual ID defined in your Remotion root file.

### Upgrade Remotion

```bash
npx remotion upgrade
```

## Video Narration – Hindi

> The following is the narration script supplied for this project. Belief-based and traditional claims are presented as part of the storytelling; verify details and wording before publishing.

### Opening

[excited] दुनिया का सबसे रहस्यमयी मंदिर...

[dramatic] जहाँ विज्ञान भी कई सवालों पर सिर खुजलाने लगता है!

[thoughtful] आखिर क्या हैं भगवान जगन्नाथ पुरी के वो आठ रहस्य?

[whispering] वीडियो को अंत तक जरूर देखना...

[short pause]

### रहस्य नंबर एक – मंदिर का ध्वज

[dramatic] मंदिर के शिखर पर लगा ध्वज हमेशा हवा की विपरीत दिशा में लहराता दिखाई देता है!

[wind blowing]

[serious] हर शाम एक सेवक... बिना किसी आधुनिक सुरक्षा उपकरण के... लगभग दो सौ फीट ऊँचे शिखर पर चढ़कर ध्वज बदलता है!

[whispering] मान्यता है कि अगर एक दिन भी यह परंपरा छूट जाए... तो मंदिर अठारह साल तक बंद रखना पड़ेगा!

[dramatic pause]

### रहस्य नंबर दो – नीलचक्र

[softly] मंदिर के शिखर पर लगा नीलचक्र...

[thoughtful] इसे पुरी में किसी भी दिशा से देखो... ऐसा लगता है मानो यह आपको ही देख रहा हो!

[short pause]

### रहस्य नंबर तीन – पक्षी और हवाई जहाज

[ominous] कहा जाता है कि मंदिर के ऊपर न तो पक्षी उड़ते हैं... और न ही हवाई जहाज!

[gasping] आखिर क्यों?

[dramatic pause]

### रहस्य नंबर चार – समुद्र की आवाज

[softly] कहते हैं... सिंहद्वार के अंदर कदम रखते ही समुद्र की लहरों की आवाज गायब हो जाती है...

[sea waves]

[whispering] और बाहर निकलते ही... फिर से सुनाई देने लगती है!

[short pause]

### रहस्य नंबर पाँच – मंदिर की छाया

[serious] इतना विशाल मंदिर...

[dramatic pause]

[whispering] लेकिन मान्यता है कि इसके मुख्य शिखर की छाया जमीन पर दिखाई नहीं देती!

[short pause]

### रहस्य नंबर छह – महाप्रसाद की रसोई

[excited] यहाँ सात मिट्टी के बर्तन एक के ऊपर एक रखकर खाना पकाया जाता है!

[thoughtful] लेकिन हैरानी की बात सुनिए...

[dramatic] मान्यता के अनुसार... सबसे ऊपर वाला बर्तन पहले पकता है... नीचे वाला नहीं!

[short pause]

### रहस्य नंबर सात – ब्रह्म पदार्थ

[whispering] अब जो रहस्य मैं बताने जा रहा हूँ... उसे सुनकर आप भी हैरान रह जाएंगे!

[heartbeat]

[slowly] कहा जाता है कि भगवान जगन्नाथ की प्रतिमा के भीतर श्रीकृष्ण से जुड़ा एक दिव्य तत्व... जिसे ब्रह्म पदार्थ कहा जाता है... सुरक्षित है।

[serious] नवकलेवर के समय पुरानी प्रतिमा से इसे नई नीम की प्रतिमा में स्थानांतरित किया जाता है।

[whispering] इस गोपनीय अनुष्ठान के दौरान... अंधेरा रखा जाता है... और पुजारियों की आँखों पर पट्टी बाँधी जाती है।

[dramatic pause]

[low voice] कुछ प्रचलित कथाओं में इसे छूने पर... जीवित खरगोश जैसी अनुभूति होने की बात भी कही जाती है!

[heartbeat]

### रहस्य नंबर आठ – भगवान जगन्नाथ के अधूरे हाथ-पैर

[serious storytelling] पौराणिक कथा के अनुसार... एक वृद्ध शिल्पकार ने राजा से कहा था कि इक्कीस दिनों तक दरवाजा मत खोलना।

[knocking on door]

[tense] लेकिन राजा से इंतजार नहीं हुआ!

[dramatic pause]

[shocked] दरवाजा खुला... तो शिल्पकार गायब थे... और भगवान की प्रतिमाएँ अधूरी थीं!

[softly] तभी से भगवान इसी दिव्य स्वरूप में पूजे जाते हैं।

[devotional] और हर साल भगवान जगन्नाथ... अपने भाई बलभद्र और बहन सुभद्रा के साथ... अपनी मौसी के घर गुंडिचा मंदिर जाने के लिए भव्य रथयात्रा पर निकलते हैं!

[crowd cheering]

### Closing

[emotional] आपको इन आठ रहस्यों में से कौन-सा सबसे अद्भुत लगा?

[excited] कमेंट में जरूर बताइए!

[powerful devotional voice] जय जगन्नाथ!!! 🙏
